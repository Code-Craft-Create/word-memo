Translations

The translations you use and their language. Passages are shown with the book names of a translation's language, for example "Johannes 3,16" for a German one. Translations not listed here are shown in English.

Merge tags

Pick the tags to merge and type the new tag. On every verse that has any of them, they are replaced by the new tag. This changes the shared verses and cannot be undone.

Reset learning progress

Sets every verse back to New, as if you had never practised it. Only your own progress is reset; the verses and the other person's progress stay as they are. To reset a single verse, use Reset progress on its card under All verses.

Back up (export)

Downloads your verses, learning sets, translations and your own learning progress as a JSON file. You can also copy the JSON and save it as a .json file.

Import

Pick a file exported from Word Memo, or paste its JSON. Verses, sets and translations you already have are kept; duplicates are skipped.
